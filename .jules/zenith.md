## 2024-04-23 - [Sprint 0 - Foundations and Scaffolding] **Learning:** Established the template-driven scaffolding foundation. The core insight is that for a multi-tenant platform with both SaaS and on-prem profiles, managing configurations and project structure through strict templates prevents drift and simplifies future upgrades. Also, managing extensibility via dependency injection instead of complex runtime plugin loaders is critical for MVP simplicity. **Action:** Future sprints must enforce that new services/capabilities are generated using the `scripts/scaffold` tool to maintain directory consistency and automatically wire in the environment profile.
